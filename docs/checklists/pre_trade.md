# C.1 Pre-Trade Checklist (Every Sleeve B Order)

- [ ] Daily Sheet action item exists and is signed off.
- [ ] Order matches the sizing formula output exactly (no discretionary adjustment).
- [ ] Limit price set per instrument rule (anchored to current book; iNAV for DRs).
- [ ] Margin utilisation after fill projected < 60% of buffer.
- [ ] Correct series (front month / roll pair) confirmed against roll calendar.
